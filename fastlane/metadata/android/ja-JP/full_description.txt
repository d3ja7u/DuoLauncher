DuoLauncher は Kotlin + Jetpack Compose で書かれた完全なホームランチャー（android.intent.category.HOME）です。Unihertz Titan 2 Elite（1080×1200 の正方形に近い画面、物理キーボード）に合わせて調整しましたが、Android 9 以降の端末で動作します。

テーマやアイコンパックではなく、既定のホームアプリとして設定できます。

主な機能

* ガラス調 UI。ぼかしの強さとライト／ダークの外観を調整可能
* iOS 風ステータスバー：時刻、電波アーク、Wi-Fi ドット。左右切り替え、12/24 時間表示
* 左右に置けるサイドドック。並び替え・編集ができ、アイコンサイズを個別設定
* アプリライブラリ：カテゴリカード表示 または A–Z リスト（排他切替）。右側の幅広い文字インデックスをタップ／ドラッグ
* アプリ即時検索。最左ページで右スワイプすると開き、左スワイプで閉じます
* アプリ・連絡先・Web 検索（百度 / Bing / Google）。Enter で最初の結果を開き、Web は既定ブラウザで表示
* 最近使ったアプリの件数を設定（5/10/15/20）、サイドドックの表示／非表示を切替
* 編集モードでアイコン左上に iOS 風の「−」：ホームから削除 / アンインストール / キャンセル
* 新規インストール時はホーム画面が空。設定から設定全体をバックアップ／復元
* 通知バッジ：8 色から選択（任意の通知アクセス権が必要）
* ジェスチャー：画面左右の下スワイプで通知欄／クイック設定、ダブルタップでスリープ
* サードパーティ製アイコンパック、アプリ個別のアイコン変更、アプリ非表示、カテゴリ手動指定
* ホーム画面ウィジェット
* 表示言語：簡体字中国語 / English / 日本語。端末の言語に自動追従し、設定から手動指定も可能
* 新版が見つかったらその場でダウンロードしてインストール（進捗表示・キャンセル可、インストールは利用者が確認）

権限と用途

* QUERY_ALL_PACKAGES：アプリライブラリと検索のため全インストールアプリを列挙します。一覧は端末外に送信しません。
* READ_CONTACTS：任意の連絡先検索のみに使用。氏名と番号は端末内で照合し、アップロードも別データベースへの保存も行いません。
* 通知アクセス：未読数を数えてバッジに表示するだけ。処理はすべて端末内です。
* アクセシビリティサービス：ダブルタップでスリープするためだけに使用。canRetrieveWindowContent は false で、画面内容や入力を読み取らず、自律的に操作することもありません。
* EXPAND_STATUS_BAR：下スワイプで通知欄／クイック設定を開きます。
* CAMERA / FLASHLIGHT：任意の懐中電灯アクション（CameraManager.setTorchMode）。
* INTERNET：後述の任意の更新確認と、利用者が明示的に開始するダウンロードのみ。
* REQUEST_INSTALL_PACKAGES：アプリ内更新でシステムのインストーラーを起動（提供元不明のアプリのインストールの許可が必要）。
* ACCESS_WIFI_STATE / ACCESS_NETWORK_STATE：独自ステータスバーの Wi-Fi・電波表示。
* VIBRATE：触覚フィードバック。REQUEST_DELETE_PACKAGES：アイコンメニューのアンインストール。
* BIND_APPWIDGET：ホーム画面ウィジェット。
* デバイス管理：アクセシビリティ操作が使えない一部 ROM 向けの代替スリープ手段。自動では有効化されず、システム設定から無効にできます。

プライバシー

広告、解析、クラッシュレポート、トラッキング SDK、Google Play Services、Firebase は一切含まれません。レイアウト・カテゴリ・設定は端末内の JSON ファイル 1 つに保存されます。アカウントもログインもなく、データやインストール済みアプリ一覧をアップロードすることはありません。設定の「バックアップと復元」はシステムのファイル選択画面から任意の場所に書き出し／読み込みするだけで、自動送信はなく、ストレージ権限も不要です。完全なプライバシーポリシー：https://github.com/d3ja7u/DuoLauncher/blob/main/PRIVACY.md

任意の更新確認は GitHub Releases API（利用できない場合は releases.atom）にバージョン情報を照会します。ダウンロードとインストールは常に利用者の明示的なタップで開始されます。「ダウンロードしてインストール」を選ぶと APK はアプリ専用キャッシュにのみ保存され、FileProvider でシステムのインストーラーに一時共有し、インストールはシステム画面で確認が必要です。バックグラウンドでの自動ダウンロードやサイレントインストールはなく、ストレージ権限も不要です。ダウンロードページを開く／リンクをコピーするだけならダウンロードは行われません。確認は手動、または自動有効時も間隔が制限され、設定で無効化できます。更新元の URL も変更可能です。GitHub はプロプライエタリなサービスであるため、NonFreeNet のアンチフィーチャーが付きます。
