DuoLauncher is a complete home screen launcher (android.intent.category.HOME) written in Kotlin with Jetpack Compose. It was hand-tuned for the Unihertz Titan 2 Elite - a near-square 1080x1200 display with a physical keyboard - and runs on Android 9+ devices.

This is not a theme or an icon pack: you can set it as your default home app.

FEATURES

* Glass-morphism UI with adjustable blur strength and light / dark appearance
* iOS-style status bar: time, cellular arc and Wi-Fi dots, switchable sides, 12/24-hour clock
* Side dock on the right or left, editable and reorderable, with its own icon size
* App library: category cards OR a strict A-Z list with a wide, draggable alphabet index (the two views are mutually exclusive)
* Instant app search; right-swipe on the leftmost home page opens it, left-swipe closes it
* Search apps, contacts or the web (Baidu / Bing / Google); Enter opens the first result, web results open in the default browser
* Configurable recent-app count (5/10/15/20); the side dock can be hidden
* Edit mode shows an iOS-style "−" on each icon: Remove from Home / Uninstall / Cancel
* Fresh installs start with an empty home screen; Settings can export / import the full configuration
* Notification badges in 8 colors (optional Notification Access)
* Gestures: split-area down-swipe for notifications / quick settings, double-tap to sleep
* Third-party icon packs, per-app icon overrides, hidden apps, manual categories
* Home screen widgets
* UI in Simplified Chinese, English and Japanese; follows the device language by default, with a manual override in Settings
* In-place updates: when a new release is found, download and install it directly, with progress, cancel and a user-confirmed install

PERMISSIONS - WHAT EACH ONE IS FOR

* QUERY_ALL_PACKAGES: the app library and search must enumerate every installed app. The list never leaves the device.
* READ_CONTACTS: only for the optional contact search. Names and numbers are matched on device; nothing is uploaded or copied into a separate database.
* Notification Access: counts unread notifications for badges, processed entirely on device.
* Accessibility Service: used only for double-tap to sleep. canRetrieveWindowContent is false, so it cannot read screen content or keystrokes. It never performs actions on its own.
* EXPAND_STATUS_BAR: down-swipe gestures that open the notification shade or quick settings.
* CAMERA / FLASHLIGHT: the optional flashlight toggle action (CameraManager.setTorchMode).
* INTERNET: only the optional update check and the in-place download you explicitly start, described below.
* REQUEST_INSTALL_PACKAGES: opens the system installer for in-place updates; requires granting Install unknown apps in system settings.
* ACCESS_WIFI_STATE / ACCESS_NETWORK_STATE: draws Wi-Fi and signal indicators in the custom status bar.
* VIBRATE: haptic feedback. REQUEST_DELETE_PACKAGES: the uninstall shortcut in the icon menu.
* BIND_APPWIDGET: home screen widgets.
* Device Admin: optional fallback for screen-off on ROMs where the accessibility action is unavailable. It is never activated automatically and can be turned off in system settings.

PRIVACY

No ads, no analytics, no crash reporting, no tracking SDK, no Google Play Services and no Firebase. Layout, categories and settings are stored in one local JSON file. There is no account and no sign-in. Nothing is uploaded, and no installed-app list is transmitted. "Backup & Restore" in Settings uses the system file picker to save the configuration wherever you choose or read it back; it never uploads anything and needs no storage permission. Full privacy policy: https://github.com/d3ja7u/DuoLauncher/blob/main/PRIVACY.md

The optional update checker queries the GitHub Releases API (or releases.atom as fallback) for version information. Whether to download or install is always your deliberate tap: after you choose Download and install, the APK is written only to the app's private cache and shared with the system installer through a temporary FileProvider grant, with the install confirmed in the system dialog. Nothing is downloaded in the background or installed silently, and no storage permission is needed. You can also just open the download page or copy the link and skip the download. The check is on demand, at most once per interval when auto-check is enabled, and can be disabled in Settings; the update source is editable or can be pointed at any endpoint. GitHub is a proprietary service, which is why this app carries the NonFreeNet anti-feature.
