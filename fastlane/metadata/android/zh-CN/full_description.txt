DuoLauncher 是用 Kotlin + Jetpack Compose 编写的完整桌面启动器（android.intent.category.HOME），为 Unihertz Titan 2 Elite（1080×1200 近方形屏、实体键盘）手工适配，同时兼容 Android 9 及以上设备。

它不是主题包，也不是图标包，可以直接设为系统默认桌面。

主要功能

* 玻璃拟态界面，模糊强度、深浅外观均可调
* iOS 风格状态栏：时间、弧形信号、Wi-Fi 点阵，可左右切换，支持 12/24 小时制
* 侧边栏 Dock 可放左/右，内容可编辑排序，图标尺寸独立可调
* App 资源库：分类卡视图 与 A–Z 字母列表二选一，右侧加宽字母索引条可点可拖
* 应用即时搜索；最左页右滑打开搜索，搜索页左滑返回
* 搜索可选应用 / 通讯录联系人 / 网页（百度、必应、谷歌），回车打开首个结果，网页用默认浏览器
* 搜索页可设置最近常用数量（5/10/15/20），侧边栏支持隐藏
* 编辑主屏时图标左上角显示 iOS 风格「−」：从主屏幕移除 / 卸载应用 / 取消
* 新安装默认空主屏；设置可导出 / 导入整份配置备份
* 通知角标：8 种颜色可选（需按需授予通知使用权）
* 手势：左右分区下滑分别呼出通知栏 / 控制中心，双击桌面息屏
* 支持第三方图标包、单应用换图标、隐藏应用、手动指定分类
* 支持桌面小组件
* 界面语言：简体中文 / English / 日本語，默认跟随设备，设置里可手动指定

权限用途说明

* QUERY_ALL_PACKAGES：资源库与搜索必须枚举全部已安装应用，应用列表不会离开设备。
* READ_CONTACTS：仅用于按需开启的「通讯录联系人搜索」，姓名与号码只在设备本地匹配，不上传、不保存副本。
* 通知使用权：仅在本机统计未读数量用于角标，不上传内容。
* 无障碍服务：仅用于「双击桌面息屏」。canRetrieveWindowContent 为 false，不读取屏幕内容、不监听按键，也不会自主执行动作。
* EXPAND_STATUS_BAR：下滑手势展开通知栏 / 控制中心。
* CAMERA / FLASHLIGHT：可选的手电筒快捷动作（CameraManager.setTorchMode）。
* INTERNET：仅用于下述可选的更新检查。
* ACCESS_WIFI_STATE / ACCESS_NETWORK_STATE：绘制自定义状态栏里的 Wi-Fi 与信号指示。
* VIBRATE：触感反馈；REQUEST_DELETE_PACKAGES：图标菜单里的卸载入口。
* BIND_APPWIDGET：桌面小组件。
* 设备管理器：仅在个别 ROM 上作为息屏的备用方案，不会自动激活，可在系统设置里关闭。

隐私

无广告、无统计、无崩溃上报、无追踪 SDK，不含 Google Play Services 与 Firebase。桌面布局、分类和设置保存在本机一个 JSON 文件里，没有账号、没有登录、不上传任何数据，也不会上传已安装应用列表。设置里的「备份与恢复」通过系统文件选择器把配置写到你自己选的位置，或从中读回，不会自动上传、不需要存储权限。完整隐私政策：https://github.com/d3ja7u/DuoLauncher/blob/main/PRIVACY.md

可选的更新检查只向 GitHub Releases API（受限时自动回退 releases.atom）查询版本信息，从不下载、安装或执行 APK。发现新版本时只弹窗提示，由你主动选择「打开下载页」或「复制链接」。检查可手动触发，自动检查有间隔限制且可在设置里关闭，更新源地址可自行修改。GitHub 属于专有网络服务，因此本应用带 NonFreeNet 标记。
