# v1.7.2 更新说明（齐老师定稿）

> 发布时把下面两段原样作为 GitHub / Gitee Release 正文（中文在前，英文在后）。
> 版本：`versionCode 229` / `versionName 1.7.2`。

## 更新说明

**新增**
- 长按桌面小组件可选择「调整大小」，按列数、行数自定义组件尺寸。
- 设置 → 侧边栏新增「侧栏图标间距」，可调整侧栏图标之间的疏密。

**修复与优化**
- 修复关闭「显示搜索页面」后，主屏首页空白、新添加的小组件显示在第二页、左右滑动回不到首页的问题。
- 修复小组件移动到其他主屏页面后不显示的问题。
- 修复部分全键盘识别问题「按键设置」无法正常显示的问题。

## What's New

**New**
- Long-press a home screen widget to resize it by columns and rows.
- Settings → Sidebar now offers "Sidebar icon spacing" to adjust how densely the sidebar icons are placed.

**Fixes & Improvements**
- Fixed the home screen shifting by one page after turning off "Show search page", which left the first page blank, put newly added widgets on the second page and made it impossible to swipe back.
- Fixed widgets not showing after being moved to another home screen page.
- Fixed the "Key settings" entry not showing on some full-keyboard devices.
