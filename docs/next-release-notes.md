## 更新说明

**新增**
- 新增桌面快捷键：在「按键设置」里为字母键指定应用或功能，短按与长按可分别设置，分身应用也可指派。
- 系统里已配置的字母快捷键会自动显示在按键格上，点击可直接前往系统设置。
- 设置页按分类整理为七个分组，顶部新增设置搜索，并新增「重置所有设置」。
- 新增「锁定布局」，开启后桌面图标不会被误移动或移除。
- 检查更新可选择 Gitee 或 GitHub 服务器，检查间隔支持 12 / 24 / 48 / 72 小时。
- 发现新版本时，桌面底部显示常驻提示，点击即可查看更新说明并下载安装。

**修复与优化**
- 优化桌面图标与小组件的移动位置体验。
- 优化设置界面外观，并适配平板等大屏设备显示效果。
- 优化桌面图标加载与翻页流畅度。
- 降低桌面功耗，切换到其他应用后不再持续刷新画面。
- 在系统中修改或删除字母快捷键后，桌面即时同步。
