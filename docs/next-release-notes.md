# v1.7.1 更新说明（齐老师定稿）

> 发布时把下面两段原样作为 GitHub / Gitee Release 正文（中文在前，英文在后）。
> 版本：`versionCode 223` / `versionName 1.7.1`（1.7.0 的修复版；1.7.0 的 Release 已删除）。

## 更新说明

**新增**
- 新增桌面快捷键：在「按键设置」里为字母键指定应用或功能，短按与长按可分别设置，titan2及titan2elite系统不支持添加的分身应用也可指派，同样适合于其他全键盘手机，需要自行测试。
- 系统里已配置的字母快捷键会自动显示在按键格上，点击可直接前往系统快捷键设置。
- 新增「锁定布局」，开启后桌面图标不会被误移动或移除。
- 检查更新可选择 Gitee 或 GitHub 服务器，可设置检查间隔，发现新版本时，桌面底部新增提示，点击即可查看更新说明并下载安装。

**修复与优化**
- 修复使用字母快捷键打开应用后，输入框仍继续输入字母的问题。
- 修复部分设备使用触摸板左右滑动切换桌面时，页面停在两页之间的问题。
- 优化启动器桌面快捷键字母键已被系统快捷键占用时，按键格会以橙色标记提示，并可直接前往系统设置清除，同一按键已在系统快捷键设置的无法同时在启动器中设置。
- 优化适配安卓17系统。
- 优化桌面图标与小组件的移动位置体验。
- 优化设置界面外观，按分类整理，并适配平板等大屏设备显示效果。
- 优化桌面图标加载与翻页流畅度。
- 优化降低功耗。

## What's New

**New**
- Desktop letter shortcuts: assign an app or action to a letter key in "Key settings", with short press and long press configured separately. Cloned apps that the Titan 2 / Titan 2 Elite system does not allow you to add can also be assigned. It also works on other full-keyboard phones — please test on your own device.
- Letter shortcuts already configured in the system appear on the key grid automatically; tap one to open the system shortcut settings directly.
- New "Lock layout" option: once enabled, home screen icons cannot be moved or removed by accident.
- Update checks can use the Gitee or GitHub server, with a configurable interval. When a new version is found, a banner appears at the bottom of the home screen — tap it to read the notes and download.

**Fixes & Improvements**
- Fixed the input box still receiving letters after opening an app with a letter shortcut.
- Fixed the home screen stopping between two pages when switching with a trackpad on some devices.
- Improved the letter key grid: a key already occupied by a system shortcut is now marked in orange, with a shortcut to clear it in the system settings; a key already set in the system shortcuts cannot be set in the launcher at the same time.
- Improved compatibility with Android 17.
- Smoother moving of home screen icons and widgets.
- Refreshed settings appearance, grouped by category, with better layouts on tablets and other large screens.
- Faster icon loading and page switching.
- Reduced power consumption.
